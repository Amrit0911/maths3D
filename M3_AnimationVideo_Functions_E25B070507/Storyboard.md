# Storyboard: Single-Variable Functions and Graphs
**Course:** Linear Algebra and Calculus (M3)  
**Topic:** Single-variable Functions and Graphs  
**Target Function:** $f(x) = x^2 - 4x + 3$  
**Target Duration:** ~5 minutes (310 seconds total)  
**Learning Objective:** *"By the end of this video, the viewer will be able to explain that a single-variable function assigns exactly one output to each input, understand that the graph is the set of points $(x, f(x))$, and systematically read roots, y-intercept, vertex, domain, range, and increasing/decreasing intervals directly from the graph."*
